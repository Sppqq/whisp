# История изменений

Здесь перечислены заметные изменения Whisp. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.1.16-alpha.8] - 2026-09-24

### Исправлено

- Для короткой лекции Whisp больше не отправляет готовую единственную часть на лишнюю повторную сборку; ответы шлюза с CCR retrieve hash автоматически заменяются реальными частями конспекта.
- Для OpenAI-совместимых кастомных моделей служебные ответы вроде «пришлите текст» больше не попадают в конспект: проблемный фрагмент сохраняется без искажений, а автоматические платные повторы и финальная повторная сборка отключены.

## [1.1.16-alpha.4] - 2026-09-23

### Изменено

- Gemini теперь на час закрепляет модель и рабочий ключ, на которых успешно прошёл fallback-запрос, чтобы следующие запросы не перебирали остальные модели и ключи.
- В настройках появилась явная кнопка «Закрыть», работающая и в отдельном окне, и в sheet.
- Если провайдер не принимает структурированный JSON при анализе, Whisp повторяет запрос обычным текстом и позволяет создать конспект из уже сохранённой расшифровки.
- OpenAI-совместимые провайдеры теперь принимают SSE-ответы, которые приходят даже при отключённом stream-режиме.

## [1.1.16-alpha.2] - 2026-09-19

### Исправлено

- Экран провайдеров упрощён: быстрые режимы «Облако», «Гибрид» и «Локально», сворачиваемые ключи и подключения, понятный маршрут «голос → текст → конспект» и автосохранение URL и моделей.
- Настройки провайдеров теперь показывают сохранённый маршрут и активную модель; голосовую расшифровку и создание конспекта можно направить через разные сервисы, включая локальный Whisper + Ollama/LM Studio.
- Новые записи на iPhone сразу попадают в индекс поиска, а локальная и автоматическая обработка блокируют повторный запуск.
- Синхронизация iPhone с WebDAV теперь защищает удалённые изменения через ETag и не запускается повторно по двойному нажатию.
- Повторное нажатие создания напоминаний больше не создаёт дубликаты; без расписания уроков напоминания не создаются с неверным сроком по умолчанию.

## [1.1.16-alpha.1] - 2026-09-19

### Исправлено

- Режим «Только локальный Whisper» больше не обращается к облачному анализу после расшифровки и сохраняет локальную стенограмму без API-ключа.

## [1.1.15-alpha.1] - 2026-09-17

### Добавлено

- Нативный клиент Whisp для iPhone: запись с микрофона, импорт аудиофайлов, облачная расшифровка, создание конспекта и общая модель библиотеки лекций.
- Функциональный паритет iPhone с Mac по библиотеке: полнотекстовый поиск, редактирование Markdown и метаданных, генерация вопросов к зачёту, экран «Сегодня», ручная синхронизация WebDAV и создание напоминаний Apple Reminders.
- Опциональный локальный WhisperKit fallback на iPhone; модель загружается только после явного включения пользователем.

- Отдельная схема `WhispiOS` и проверка iPhone-сборки в pull request workflow; macOS и iOS теперь собираются из одного XcodeGen-проекта.

### Изменено

- Общие модели лекций, Gemini-клиент, анализ, Markdown-экспорт и локальное хранилище используются обоими приложениями, а desktop-функции изолированы от iOS.
- Нижняя панель лекции собрана в одну компактную капсулу с иконками WebDAV и Reminders; ключи Gemini отображаются вертикальным списком с явным добавлением и удалением.
- Статус обработки на iPhone получил компактную анимированную плашку; новые записи сохраняются в моно AAC с битрейтом 64 кбит/с для заметно меньшего размера.
- Длинные статусы загрузки аудио в плашке обработки больше не обрезаются и отображаются в компактном переносе.
- Импортируемые аудиофайлы теперь сначала перекодируются в компактный M4A перед отправкой в AI; исходный файл пользователя не изменяется.
- Во время сжатия импортированного аудио показывается фактический процент прогресса.

### Исправлено

- Пароль WebDAV теперь сохраняется в защищённом хранилище при изменении поля; кнопка запроса доступа к Reminders скрывается после выдачи разрешения.

## [1.1.14-alpha.16] - 2026-09-13

### Добавлено

- Экран «Сегодня» объединяет ближайшие занятия, актуальные задания из лекций и тесты, которые пора повторить.

- Для вопросов, отмеченных как сложные, повторение предлагается на следующий день; для успешно пройденных — через неделю.

- Плавные переходы связывают навигацию по сайдбару, смену лекций, вкладок документа и режимов просмотра; системная настройка уменьшения движения соблюдается.

### Изменено

- Готовые лекции больше не помечаются словом «Проверка» в библиотеке; внутренний статус просмотра переименован в понятное «Готово».

- Активные и неактивные кнопки «Сегодня» и фильтров предметов получили различимые Liquid Glass-состояния, а кнопки новой лекции и инспектора — одинаковую круглую форму.

### Исправлено

- Плашки ключевых понятий показывают чистые названия без служебных скобок `[[…]]`; Obsidian-ссылки в Markdown при этом сохраняются.

- Кнопки действий под вкладками конспекта остаются по центру, в том числе когда отображается только «Копировать».

- Кнопка «Сегодня» больше не отменяет собственный переход при сбросе выбранной лекции и нажимается по всей площади стеклянной плашки.

## [1.1.13-alpha.24] - 2026-09-10

### Добавлено

- Выбор списка Apple Reminders в настройках, например «Учёба» или «Домашка».
- Задания из лекции теперь сохраняются и в заметках Obsidian, даже если Apple Reminders недоступен или отключён.
- В проверке лекции появился блок заданий к следующему уроку: найденные поручения можно просмотреть и вручную повторно добавить в Apple Reminders, если расписание или доступ были настроены позже.
- Интеграция с Apple Reminders: Whisp выделяет реальные задания из лекции и создаёт напоминания с коротким названием, подробным описанием и сроком ближайшего урока.
- Настройки расписания уроков по дням недели и времени с автоматическим определением следующего занятия.
- Поддержка локальных и открытых провайдеров LLM: Ollama (`http://localhost:11434/v1`), LM Studio (`http://localhost:1234/v1`) и Unsloth (`http://localhost:8000/v1`).
- Поддержка работы без обязательного API-ключа для локальных сервисов с опциональной авторизацией Bearer.
- Автоматическая очистка JSON-ответов локальных моделей от блоков markdown (````json````) и тегов рассуждений `<think>...</think>`.
- Диагностика и информативные подсказки при недоступности локальных серверов (проверка `ollama serve`, Local Server в LM Studio).
- Редизайн приложения для macOS 26 в едином стиле Liquid Glass: библиотека, плеер, тулбары, карточки записи, онбординг и настройки адаптированы под системные гайдлайны и палитру.
- Inspector выбранной лекции (`SessionInspectorView`): детальная боковая панель с параметрами обработки, метриками уверенности AI, длительностью и источниками звука, числом сегментов и ручных правок, статусом WebDAV и активным провайдером.
- Быстрые действия в панели Inspector: «Сохранить в Obsidian», «Открыть в Obsidian» и «Показать файлы» без переключения экранов.
- Прогрессивная двухэтапная генерация конспекта: стенограмма и плеер открываются сразу после завершения распознавания речи, а конспект генерируется частями (блоками по 20–30 секунд) с живым отображением промежуточного прогресса на экране.
- Автоматическая консолидация конспекта AI-редактором: объединение сгенерированных фрагментов лекции в единый связный текст с сохранением логических переходов.
- Цепочка отказоустойчивости AI-моделей (Fallback chain): автоматический переход `gemini-3.8 → gemini-3.7-flash → gemini-3.6-flash → gemini-3.5-flash-lite` при исчерпании квот или ошибках сети после трёх попыток с ротацией API-ключей.
- Экран полного списка изменений (`PostUpdateView`): показ актуального changelog текущей сборки после обновления приложения напрямую из бандла.
- Локализованный выбор даты лекции: кнопка формата `ДД.ММ.ГГГГ` с графическим календарём во всплывающем окне для быстрой правки даты.

### Изменено

- Расписание в настройках переработано в недельную сетку из колонок по дням; уроки добавляются прямо в нужный день, а предмет выбирается из списка дисциплин.
- Библиотека лекций переведена на системную навигацию macOS 26 (`NavigationSplitView`) с поддержкой `.searchable`, увеличенными отступами между категориями и нативным сайдбаром.
- Настройки приложения переработаны на стандартную структуру списка macOS с системным выделением активного пункта и разделом «Провайдер».
- Экран записи оснащён плавающим стеклянным dock-контроллером с кнопками паузы и завершения.
- Стартовый экран объединён в компактный функциональный стеклянный блок выбора микрофона и системного звука с поддержкой drag-and-drop.
- Выбор предмета в шапке лекции переведён на компактное стеклянное меню с иконкой вместо текстовой метки.
- Тулбар окна и кнопки управления приведены к нативному виду: кнопка инспектора выполнена круглой icon-only кнопкой в стиле Liquid Glass, а текстовый конспект размещён на спокойной подложке без лишних вложенных слоёв.

### Исправлено

- Устранено падение при удалении урока из недельного расписания.

- Исправлен запрос доступа к Apple Reminders: добавлено обязательное описание полного доступа для macOS, чтобы системный диалог разрешения отображался корректно.
- Экспорт конспектов в Obsidian теперь сохраняет Properties/frontmatter в исходном виде при ручных правках и повторной генерации AI.
- Локально отсутствующие аудиофайлы больше не добавляются в Markdown-экспорт как повреждённые Obsidian-вложения.
- Повышена надёжность WebDAV-синхронизации: проверка прав на запись реальным методом `PUT` вместо заголовка `Allow`, безопасное ограничение длины русскоязычных имён файлов по UTF-8 и автоматическая пересборка путей при повторной отправке.
- Устойчивость расшифровки длинных аудиозаписей: тихие фрагменты больше не прерывают процесс, неполные ответы автоматически повторяются с ротацией ключей, а пятиминутные сегменты сохраняются для продолжения.
- Устранены визуальные дефекты тулбаров: заголовок скрытого инспектора больше не просачивается в заголовок окна, убраны лишние подложки кнопок.
- Удалена дублирующая вкладка «Сырой звук»: аудиозапись остаётся доступной в плеере и экспорте, а текстовый просмотр — во вкладке «Стенограмма».

### Совместимость

- Минимальная поддерживаемая версия ОС повышена до macOS 26.0 для использования нативных SwiftUI API Liquid Glass.

- В списке лекций убрана длительность слева в нижней строке карточки для более чистого и компактного вида.

## [1.1.7] - 2026-09-06

### Добавлено

- Автоматическое обновление приложения в один клик: Whisp скачивает образ DMG новой версии, фоново валидирует пакет, завершает работу, подменяет приложение в `/Applications` и автоматически перезапускается.
- Защита от прерывания активной записи лекции при попытке обновления.

## [1.1.6] - 2026-09-06

### Изменено

- Экран записи показывает один понятный статус вместо ряда технических индикаторов; подробности Gemini, Whisper, прокси и WebDAV доступны по клику.
- В библиотеке лекций появились длительность, дата, состояние дорасшифровки и отметка ручных правок.
- Поиск по стенограмме показывает число совпадений, а у таймкодов появились явные подсказки для перехода к аудио.

## [1.1.5] - 2026-09-06

### Добавлено

- Импорт нескольких аудиофайлов за один раз через выбор файлов или перетаскивание в стартовую карточку.
- Очередь импорта: записи обрабатываются последовательно, а следующие файлы видны на экране прогресса.
- Диагностика Gemini при ошибке обработки: число ключей, их статус и ручная проверка подключения.

### Исправлено

- Если расшифровка уже сохранена, повтор после сбоя запускает только генерацию конспекта и не отправляет аудио повторно.
## [1.1.4] - 2026-09-06

### Исправлено

- В beta-сборках из DMG горячие клавиши больше не создают системный перехватчик событий. Это устраняет ситуацию на macOS 27, когда окно Whisp отображалось, но не принимало клики, включая кнопки закрытия.
- Горячие клавиши работают, пока активно окно Whisp. Глобальное управление будет возвращено после подписи Developer ID и notarization.

## [1.1.3] - 2026-09-06

### Исправлено

- GitHub Release теперь собирается на Apple Silicon runner с macOS 26 и штатным новым Xcode, как локальная рабочая сборка на beta-версии macOS.

## [1.1.0] - 2026-09-06

## [1.0.0] - 2026-09-06

### Добавлено

- Запись микрофона и дополнительная запись системного звука отдельными M4A-дорожками.
- Импорт готовых аудиофайлов.
- Живая и финальная расшифровка через Gemini с поддержкой нескольких API-ключей.
- Локальное резервное распознавание через WhisperKit и последующая дорасшифровка.
- Представления «Тетрадь», «Разбор», «К зачёту», «Стенограмма» и «Исходный текст».
- Markdown-просмотр, ручное редактирование, тренажёр и экспорт в Obsidian через WebDAV.
- Поиск, предметы, теги, menu bar и глобальные горячие клавиши.
- Выбор между локальным хранением секретов и macOS Keychain.
- Установка из DMG, опубликованного в GitHub Releases. Подписанный и notarized выпуск включается после настройки Apple Developer secrets.

### Надёжность

- Обработка возобновляется с сохранённых блоков после сбоя.
- Установщик сохраняет предыдущую версию приложения до успешной замены.
- Добавлены проверки импорта аудио, Markdown, экспорта, сессий и объединения стенограммы.

### Безопасность

- API-ключи, пароли, пользовательские записи и локальные настройки исключены из репозитория.
- Перенос секретов между хранилищами проверяется до удаления исходной копии.
