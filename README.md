# Whisp

Личное нативное приложение для macOS: запись лекций, Gemini Live + локальный Whisper,
восстановление пропущенных облаком интервалов, конспект и синхронизация с Obsidian через WebDAV.

## Что уже реализовано

- отдельная запись микрофона и системного звука пятиминутными M4A-сегментами;
- сохранение состояния после каждого сегмента и восстановление аварийной сессии;
- Gemini 3.5 Transcribe Live через HTTP/SOCKS5-прокси;
- WhisperKit Large v3 Turbo как параллельная локальная страховка;
- точные `FallbackInterval` с причиной, временем и состоянием backfill;
- уведомление о восстановлении Gemini и сравнение локальной/облачной версии;
- финальная обработка блоками, классификация предмета и подробный Markdown-конспект;
- Keychain для ключа и паролей;
- WebDAV `PROPFIND`/`MKCOL`/`PUT`/`MOVE` с проверкой результата;
- русский SwiftUI-интерфейс, menu bar и глобальные горячие клавиши;
- unit-тесты критической логики сшивания и экспорта.

## Сборка на M5

Требования: macOS 15+, Xcode 16+ и Homebrew. На macOS 27 beta используйте соответствующую beta-версию Xcode.

### Сборка и переустановка одной командой

На **Mac**, в терминале из папки проекта:

```bash
bash scripts/reinstall.sh
```

Либо один раз выполните `chmod +x "Reinstall Whisp.command"`, затем запускайте этот
файл двойным кликом. Скрипт сам установит XcodeGen через Homebrew, если он отсутствует,
перегенерирует проект, выполнит XCTest, соберёт Release, проверит подпись, закроет Whisp,
заменит `/Applications/Whisp.app` и откроет именно установленную копию. Перед запуском
завершите активную запись. Не запускайте скрипт через `sudo`: он сам запросит пароль,
если запись в `/Applications` требует прав администратора.

Если Xcode открыт, но терминал настроен на Command Line Tools, скрипт автоматически
найдёт Xcode в Applications (включая beta) или через Spotlight и задаст `DEVELOPER_DIR`
только для этой сборки. Системный `xcode-select` не меняется. Конкретную версию можно
выбрать явно: `DEVELOPER_DIR="/Applications/Xcode-beta.app/Contents/Developer" bash scripts/reinstall.sh`.
Указанный вручную, но нерабочий путь выводится как ошибка, а не заменяется другой версией.

Если сборка или тесты не прошли, установленная версия остаётся на месте.
Предыдущий `.app` сохраняется в скрытой папке `/Applications/.Whisp-install.*/Previous.app`
(точный путь выводится в терминале). При ошибке замены скрипт пытается вернуть его назад.
Резервные копии автоматически не удаляются. Записи в Application Support, настройки,
Whisper-модели и Keychain не очищаются. При ad-hoc подписи macOS может повторно запросить
разрешения. Лог запуска находится в `build/reinstall-YYYYMMDD-HHMMSS.log`.

На Windows этот скрипт намеренно прекращает работу: SwiftUI/AVFoundation и Xcode
нельзя собрать здесь в рабочее macOS-приложение.

### Исправления 1.0.1 — 2026-09-02

- Единый запрос Transcribe без `custom_vocabulary` при таймкодах и диаризации
  (словарь остаётся в Live). Несовместимость подтверждена в
  [документации Gemini](https://ai.google.dev/gemini-api/docs/transcribe#custom-vocabulary).
- Разбор REST `steps/content/annotations/word_info`, секунд вида `0.100s` и speakers;
  общий `output_text` больше не затирает подробные таймкоды.
- Повторяющиеся слова сохраняются; перекрытия пятиминутных блоков распределяются
  по времени. Идентификаторы голосов не выдаются за доказанные роли преподавателя/студента.
- Обработанные блоки сохраняются в `transcript-*.json`. «Повторить обработку» продолжает
  тот же импорт с сохранённых блоков при неизменном аудиофайле и модели.
- Старые импорты без `audioChunks` восстанавливаются из сохранённого `Микрофон.m4a`.
  Новые импорты сохраняют путь к оригиналу ещё до конвертации.
- Во время обработки нельзя переключить сессию или начать другой импорт; старый
  аудиомикс и отменённые фоновые повторы не переходят в другую сессию.
- Проверка Gemini использует Interactions, а не несовместимый `generateContent`.
  Файлы ожидают состояния ACTIVE; временные облачные загрузки удаляются по возможности.
- Аудиоэкспорт заменяет старый результат только после успешного экспорта;
  ручная правка финального Markdown сохраняется при пересоздании конспекта.

Регрессионные тесты находятся в `WhispTests`. Если `ex.m4a` лежит в корне проекта,
тест AudioImportTests проверяет AVFoundation-импорт фрагментов начала, середины и конца
этой записи локально, без API и без передачи записи в облако. Скрипт запускает тесты
автоматически перед установкой. Полная проверка Gemini требует ключа в самом приложении.

Отдельная безопасная проверка установщика (с подставными Xcode/macOS-командами и
временной папкой вместо `/Applications`): `python scripts/test_reinstall.py`.
Проверка определения Xcode: `python scripts/test_select_xcode.py`.

```bash
chmod +x scripts/bootstrap.sh scripts/build_dmg.sh
./scripts/bootstrap.sh
```

В Xcode выберите локальную команду подписи или оставьте ad-hoc для личного запуска. При первом старте macOS запросит доступ к микрофону и записи экрана. Затем откройте настройки Whisp, вставьте новый Gemini API Key, настройте прокси и WebDAV и нажмите кнопки проверки.

Для DMG:

```bash
./scripts/build_dmg.sh
```

Файл появится в `dist/Whisp.dmg`.

## Секреты

Ключи и пароли не входят в исходники и DMG. Они сохраняются в macOS Keychain. Ранее опубликованные в чате значения следует заменить перед использованием.

## Проверка перед первой реальной парой

1. Записать 2–3 минуты микрофона и системного звука.
2. Отключить сеть на 30 секунд и убедиться, что появился участок `локальная страховка`.
3. Восстановить сеть и проверить предложение дорасшифровки.
4. Открыть итоговые Markdown и обе M4A-дорожки.
5. Проверить тестовую загрузку в отдельную папку WebDAV.
