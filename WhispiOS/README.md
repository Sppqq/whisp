# WhispiOS — заморожено

iPhone-клиент Whisp **заморожен** и больше не обновляется.

- Новые функции, исправления и редизайн выходят только для macOS.
- Код в этой папке остаётся как есть и может отставать от общего кода в `Whisp/`; сборка не гарантируется.
- Публичных iOS-релизов нет, клиент можно собрать только из исходников через Xcode (схема `WhispiOS`) на свой риск.
- ИИ-агентам и контрибьюторам: не менять эту папку, пока заморозка не снята явным решением владельца проекта.
